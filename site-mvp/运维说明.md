# 本地运维说明

## 服务启动与停止

在 `site-mvp` 目录执行：

```powershell
.\scripts\start-all.ps1
```

启动 MySQL、同步数据库结构及种子数据，并启动后端和前端。访问地址：

- 前端：`http://localhost:5173/zh`
- 后端健康检查：`http://localhost:8080/api/v1/health`

停止本地服务：

```powershell
.\scripts\stop-all.ps1
```

## 后台账号

P0 只支持两个固定角色：

| 角色 | 用途 |
| --- | --- |
| `ADMIN` | 管理员，可访问全部后台功能和数据报表。 |
| `OPERATOR` | 运营编辑，可维护内容，但不能访问数据报表。 |

不提供账号管理页面、邀请流程或通用 RBAC 配置。账号直接写入 `admin_user` 表，但**只能保存 BCrypt strength 12 密文，严禁保存明文密码**。

### 生成 BCrypt-12 密文

脚本会安全提示输入密码，并将密码通过标准输入传给临时 Java 程序；明文不会写入文件或命令行参数。

```powershell
Set-Location "d:\Zelin\Chemical\site-mvp"
$hash = .\scripts\Get-BcryptPasswordHash.ps1
$hash
```

首次使用前请确保已在 `backend` 目录执行过 `mvn test` 或 `mvn package`，以下载 Spring Security BCrypt 及其日志依赖。

### 创建或重置固定账号

使用刚生成的 `$hash` 写入账号。相同用户名会更新密码、角色和启用状态；脚本不会输出或记录明文密码。

```powershell
.\scripts\New-AdminUser.ps1 -Username "admin" -Role ADMIN -PasswordHash $hash
```

为运营编辑生成另一组独立密码和密文：

```powershell
$operatorHash = .\scripts\Get-BcryptPasswordHash.ps1
.\scripts\New-AdminUser.ps1 -Username "operator" -Role OPERATOR -PasswordHash $operatorHash
```

账号创建后无需重启后端，即可前往 `http://localhost:5173/zh/admin/login` 登录。

> `must_change_password` 已在数据表中标记为 `1`，用于后续强制修改密码流程。当前 P0 尚未提供修改密码页面或接口；需要更换密码时，使用上述“生成密文 + 重置固定账号”流程。

## 数据库同步

执行以下脚本会应用 schema、产品中心扩展、后台认证表和种子数据：

```powershell
.\scripts\db-check-and-sync.ps1
```

脚本会检查 `admin_user`、产品、询盘、SEO 等必要表是否存在。

## 后台变更验证流程

后台包含登录会话和 CSRF 防护时，不能只用 curl 或 Mock 用户验证。每次涉及后台写操作、图片上传或权限调整时，按以下顺序验收：

1. 执行 `./scripts/db-check-and-sync.ps1`，确认迁移和必需表完整。
2. 在 `backend` 目录执行 `mvn test`；其中必须包含真实“登录 → 获取 CSRF → 带会话和 CSRF 写入”的集成测试，不能只使用 `@WithMockUser`。
3. 在 `frontend` 目录执行 `npm run build`。
4. 通过前端开发地址实际登录，确认会话恢复和 CSRF 初始化完成。
5. 使用浏览器文件选择器上传真实代表性素材，确认预览显示 `CONTAIN`、4:3 白底画布和输出大小限制。
6. 保存关联分类、系列或产品后刷新页面，再次编辑并确认图片关系已持久化。
7. 分别验证 ADMIN 与 OPERATOR：前者可进入数据概览，后者应收到 403；未登录写入必须收到 401/403。
8. 记录所用代表性素材、浏览器结果和构建/测试结果；出现浏览器失败时，优先补充可复现的集成或端到端测试后再修复。
